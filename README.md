# 精油島 · 一步一步熟悉精油

登入會員編號後，跟著小人走遍一座等角小島：認識精油 → 稀釋與安全 → 30 天打卡 → 配方 → 手作 → 查詢 → 分享 → 方案工坊 → 夥伴的故事。
純前端、無建置步驟。地形與建築使用 Kenney 的 CC0 貼圖（`assets/`），樹、小人、小船與海面由 Canvas 2D 程式繪製，
背景音樂由 Web Audio 即時產生（不需要音檔）。素材來源與授權見 `assets/LICENSE-kenney.txt`。

線上玩：https://cornming.github.io/essence-island/

## 執行

`index.html` 不能直接雙擊開啟（瀏覽器會擋掉部分功能），請用任一靜態伺服器，在這個資料夾內執行：

```bash
python -m http.server 5173
```

再開 http://localhost:5173/

## 重點設定（`data.js` 的 `config`）

- **會員編號驗證**：`verifyMember` 預設只檢查格式（5–12 位數字），進度依編號存在這台裝置的 `localStorage`。
  要驗證名單時，在這裡呼叫你自己的 API，回傳 true / false。
- **背景音樂**：`bgm.src` 留空 = 即時產生舒緩的環境音樂；填音檔路徑 = 改播該檔並循環。右下角 🎵 可開關，偏好會記住。
- **品牌名稱與免責聲明**：`brand`、`disclaimer`。

## 方案工坊（PV 方案表）

網站**沒有內建任何真實價格或 PV**。使用者在頁面上匯入自己的價目表，資料只存在他瀏覽器的 `localStorage`（依會員編號分開），不會上傳。

- **匯入**：選 CSV / JSON 檔，或直接貼上（從 Excel 複製的表格也可以）。第一列要有欄位名稱，至少需要 `name`（品名）和 `pv`；
  其餘 `sku`（項目編號）、`ws`（批發價）、`rt`（零售價）、`cat`（分類）選填，中英文欄位名都認。頁面上有「下載 CSV 範本」。
- **級距與組合**：自己決定要做哪些 PV 級距，替每個級距挑商品；「自動調整數量」會在選好的商品裡（每項最多 6 個）找出「達到目標 PV、超出最少」的組合。
- **輸出**：下載圖片（html2canvas）、Excel（SheetJS）、HTML。這兩個函式庫只在按下按鈕時才從 cdnjs 載入，資料不會被送出。
- **範例資料**：`config.plan.sample` 是假資料，只用來示範格式；要換成別的預設，改那裡即可（不要把真實價格放進公開 repo）。
- 方案表固定附上「價格與 PV 以官方公告為準、不代表任何收入或獎金承諾」的聲明（`config.plan.disclaimer`）。

## 夥伴的故事（串接 `/api/content`）

資料來自團隊工具站 `https://jennyteam-toolbox.netlify.app/api/content` 的 `sharers`（每則：姓名、聘階、開場、金句、適合你如果、教你什麼、標籤、影片連結與時間點…）。
畫面一次顯示 10 則（`config.stories.pageSize`），捲到底時用 IntersectionObserver 再載入下一批，也可以按「載入更多」；上方可搜尋姓名、關鍵字與標籤。

這個 API 需要登入（回 401），而且沒有開放其他網域讀取（沒有 CORS）。所以資料來源依序是：

1. **即時連線**：把本站放在與 API **同一個網域**底下、`config.stories.endpoint` 填 `/api/content`，就會帶著登入狀態直接讀。
2. **匯入**：在團隊工具站登入後，主控台執行頁面上那行指令複製出 `sharers`，貼進來或選檔案。資料只存在這個瀏覽器的 `localStorage`（依會員編號分開），可隨時清除。
3. **範例**：25 則假資料，示範用。

repo 裡**沒有任何真實故事**；內容屬於團隊內部學習資料，請勿外流。畫面上所有文字都經過跳脫，影片連結只接受 https 的 YouTube 網址。

## 島嶼生活

學習之外，讓島有東西可以玩、可以收集、每天有理由回來：

- **水滴市集**（`config.shop` 改商品與價格）：用學習賺到的水滴買植物、裝飾、小動物，點「擺到島上」後在空草地上點一下放下，可以收回。路燈與紅燈籠夜裡會發光，小動物會晃來晃去、點牠會有反應。
- **居民**（`villagers` / `chat`）：三位居民在道路上散步，點他們聊天（每人每天第一次 +1 水滴）。
- **每日任務與徽章**（`js/quest.js`）：每天固定抽出 3 項任務（今日精油一定在內），做完領水滴，全領再有額外獎勵；連續登入有登入獎勵；20 個徽章，每個 +10 水滴。
- **遊樂亭**（`js/play.js`）：香氣配對、稀釋挑戰（用跟稀釋計算器同一條公式）、香氣猜猜。每款遊戲每天第一次完成拿全額，之後每場 1 水滴，每天遊戲獎勵上限 24。
- **天氣與日夜**：島上的白天、夜晚跟著使用者現在的時間；晴 / 多雲 / 雨 / 花瓣會隨機變化，點左上角的天氣晶片可以自己換。測試或截圖時可以加網址參數固定，例如 `?hour=22&weather=rain`。
- **音效**：點擊、翻牌、買東西、擺放、完成遊戲都有短音效，和背景音樂共用右下角的 🎵 開關。

進度（水滴、背包、擺設、任務、徽章、連續登入）都存在這個瀏覽器的 `localStorage`，依會員編號分開；舊版存檔會自動補上新欄位。

## 手機操作與效能

- **觸控**：一指拖曳平移、輕點選取 / 聊天 / 擺放（手指抖動 10 px 內仍算輕點）、雙指捏合縮放並可同時平移；放掉一指後剩下的手指會繼續平移，不會被誤當成輕點。滑鼠與滾輪維持原樣。
- **渲染**：不會變的東西畫一次就存成圖——地形、岸邊光暈、樹、建築氣泡（含陰影）、emoji、夜裡的光暈與雲，之後每幀只貼圖。在 CPU 降速 4 倍、手機尺寸下，最慢的場景（夜晚雨天）每幀從約 10–17 ms 降到約 7 ms，p95 從 27 ms 降到 11 ms。
- **該停就停**：島捲出畫面、被視窗蓋住或分頁在背景時不重畫。
- **自動降畫質**：約 1.5 秒內平均低於 38 fps，就把解析度上限依序降到 1.5、1（`console.info` 會留一行紀錄）。網址加 `?dpr=1` 可固定解析度；加 `?perf` 會開啟分段計時（`World.prof.acc`）。

## 新增學習站

在 `buildings` 加一筆 `kind: 'station'`：`x, y` 放在草地 `g`、`door` 放在相鄰道路 `p`，
`after` 指定要先完成哪一站，`pages` 放課程頁（`info` / `quiz` / `checklist` / `favorite` / `tool`）。
改完用 `node --check js/data.js` 檢查語法。
